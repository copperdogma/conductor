silent continued burning. Other scheduled jobs' existing exactly-20% admission
rule was preserved.

reports Fast as unverified; it never pretends a prose request set the speed.

belong in the active record. Two minutes is a polling cadence, not guaranteed
continuous monitoring; app/computer availability and dispatch/closeout latency
matter. Use fewer concurrent workers or an earlier drain when burn rate threatens
